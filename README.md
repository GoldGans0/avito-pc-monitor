# Avito PC Monitor — подготовка

Проект пока **не получает реальные объявления**. Почасовой сбор отключён:
доступ к Авито не подтверждён, разрешённый источник данных не настроен.
Actions запускает только проверку кода и синтетических карточек при изменениях.
Никаких запросов к Авито, платных сервисов, паролей или токенов здесь нет.

## Что готово

- Разбор локального HTML с карточками `data-marker="item"`.
- Фильтр Чебоксар по пути объявления и положительной цены до 80 000 ₽ включительно.
- Первый успешный разбор сохраняет все подходящие карточки и новые кандидаты.
- Повторный разбор исключает уже встреченные ID из новых кандидатов.
- Нераспознанная страница завершает команду с ошибкой, сохраняет диагностику
  и не стирает предыдущую успешную выдачу или исходный список ID.
- Каждая выдача помечена `verified_live: false`: HTML не доказывает актуальность объявления.

## Проверка

Python 3.12, без дополнительных библиотек:

```sh
python -m unittest discover -s tests -v
python monitor.py --html tests/fixtures/sample.html --output test-output
```

`tests/fixtures/sample.html` — полностью вымышленные данные для тестов.
Результаты тестов не являются объявлениями или рекомендациями покупки.

Для обработки предоставленного HTML можно использовать ту же команду с путём
к своему файлу. Результаты сохраняются в `status.json`, `feed.json`, `seen.json`
в выбранной папке. Скрипт не скачивает страницы и не отправляет уведомления.

## Что осталось

Выбрать доступный разрешённый источник, проверить реальные карточки и полноту
парсинга, затем отдельно подключить сбор и расписание. Качество комплектующих,
выгодность цены и связь с ChatGPT в этой версии не проверяются.

Не загружайте в публичный репозиторий HTML с личными данными, cookies,
пароли, токены или файлы `.env`. Actions имеет только право чтения кода.
